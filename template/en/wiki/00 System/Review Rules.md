# Review Rules

> Standards and workflow for promoting knowledge from evidence to stable layers.

## Promotion Path

```
raw -> source -> atom -> concept/method/entity/topic -> synthesis
```

## Default Thresholds

| Condition | Recommended Action |
|-----------|-------------------|
| Concept/method/entity reused by 2+ domains | Promote to Core layer |
| Conclusion supported by 3+ sources | Promote to synthesis |

## Page Depth (Bloom)

| Type | Minimum Required |
|------|-----------------|
| concept | understand |
| method | apply |
| topic | analyze |
| synthesis | create |

## Feynman Gate

Before promoting from draft to stable:
1. Explain it in ~150 words in your own words
2. Provide at least 1 positive example or use case
3. State applicability boundaries or when NOT to use
