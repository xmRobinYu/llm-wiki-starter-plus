# 评审规则

> 知识从证据层晋升到稳定层的标准与流程。

## 晋升路径

```
raw -> source -> atom -> concept/method/entity/topic -> synthesis
```

## 默认阈值

| 条件 | 建议操作 |
|------|---------|
| 概念/方法/实体被 2+ 领域复用 | 晋升到核心层 |
| 结论由 3+ 来源共同支持 | 晋升为 synthesis |

## 页面完成度（Bloom）

| 类型 | 最低要求 |
|------|---------|
| concept | understand |
| method | apply |
| topic | analyze |
| synthesis | create |

## 费曼门槛

页面从 draft 晋升到 stable 前：
1. 能在约 150 字内用自己的话解释清楚
2. 能举出至少 1 个正例或应用场景
3. 能说明适用边界或何时不适用
